## Описание реализации функций обработки изображений

### Функция изменения разрешения изображения
Сначала вычисляются коэффициенты масштабирования
- Коэффициент растяжения(сжатия) по ширине = Новая ширина/Старая ширина 
- Коэффициент растяжения(сжатия) по высоте = Новая высота/Старая высота

Строится матрица 3x3 (заполняется фактически 2x2, тк нижняя строка ),
где первые 2 диагональных элемента это полученные коэффициенты.

С помощью функции **cv2.warpAffine(img, M, (new_w,new_h))** производится линейное преобразование (только сжатие или растяжение)
Фактически, получаем обратное отображение (к каждому пикселю нового изображения получаем отображение на старое изображение)

### Функция перевода изображения в оттенки серого
Фактически это сжатие цветового пространства с 3 -> 1 (или с 4 -> 1)
Где оставшееся значение для каждого пикселя это его яркость (0.0 - > 255.0 тип np.uint8)
Строим матрицу преобразования (строку) 1x3: **[0.114,0.587,0.299]** - коэффициенты преобразования в серый (BGR)
Далее умножаем каждый пиксель (а это столбец) 3x1 на эту матрицу преобразования и получаем матрицу чисел - значений яркости (оттенки серого)

### Функция применения фотоэффекта "антиквариат" (Antique) к изображению.
Включает в себя размытие, Шум+Царапины+Пятна (см. old_photography) и эффект сепии, виньетку
#### Размытие реализовано через pyrDown и pyrUP:
- pyrDown Размытие гаусса, чтобы предотвратить появление артефактов, затем удаление всех четных строк и столбцов - получается изображение в 2 раза меньше исходного
- pyrUP - Вставка нулей (изображение увеличивается в 2 раза), затем размытие гаусса 
#### Шум+Царапины+Пятна (см описание фильтра старой фотографии)
#### Эффект сепии:
-  Переводим в оттенки серого (1 цветовой канал яркость, см соответствующий пункт выше)
-  Возвращаем к BGR с коэфф получения "сепии" ([0.20],[0.75],[1.07]) - это строка 1x3 которую мы умножим на каждый пиксель (**cv2.transform()**)
-  Цвет каждого пикселя умножился на коэффициенты "сепии", картинка соответствующе выцвела.
#### Виньетка:
Создается черное изображение исходного размера **np.zeros(res.shape)**
На него в центр добавляется окружность белого цвета. **cv2.circle(np.zeros(res.shape),(res.shape[1]//2,res.shape[0]//2),res.shape[0]//2,(255,255,255),-1)**
Размываем края окружности размытием гаусса. Далее в маске в цетре должны быть 1, а по краям коэфф < 1. 
Обрезаем np.clip(0.0,255.0)/255.0, чтобы решить проблему с переполнением и неверными коэффициентами
Далее умножаем (матричное умножение) изначальное изображение на маску и получаем затемненное по углам изображение.

### Функция выцветания (Fade Color) изображения.
Функция состоит из умножения каждого пикселя на коэффициент уменьшения яркости с последующим прибавлением к ним же константы, чтобы поднять черный цвет, что уменьшит контрастность.
Здесь аналогично строим матрицу преобразования
extent - сила выцветания (коэф float) (default = 1)
    factor = 0.8 * extent # Коэфф снижения контраста
Матрица соответственно примет вид:
    [factor, 0, 0],
    [0, factor, 0],
    [0, 0, factor]
Домножаем каждый пиксель на нее (т.е. каждый канал цвета каждого пикселя умножится на factor ) с помощью **cv2.transform()**
    lift = 80 * extent  #поднятие черного
Посчитанную константу поднятия черного прибавляем к каждому пикселю через **cv2.add()**

### Функция имитация пленки (негатив).
Я выбрал негативную пленку - это инвертирование цветов.
Технически: 255 - значение канала цвета для каждого канала каждого пикселя изображения
Поступаю просто: создаю пустую матрицу белого цвета **np.full(res.shape,255,dtype=np.uint8)**
И вычитаю из нее (матричное вычитание) исходное изображение: **cv2.subtract(mask, res)**

### Функция, обеспечивающая наложение эффекта маски (Matte).
Этот эффект делает края фотографии белыми, создавая овальную рамку вокруг центральной ее части.
Аналогично тому как это реализовано в виньетке:
Создается белое изображение исходного размера **np.full(res.shape,255,dtype=np.uint8)**
На него в центр добавляется эллипс черного цвета. **cv2.ellipse(mask,(res.shape[1]//2,res.shape[0]//2),(res.shape[1]//2,res.shape[0]//2),0,0,360,(0,0,0),-1)**
Складываем (матричное сложение) это с исходником, обрезаем np.clip(0.0,255.0).astype(np.uint8), чтобы решить проблему с переполнением и вернуть исходный тип.
Получаем закономерный результат.

### Функция добавления царапин и шума, обеспечивающих эффект состаренной фотографии.
В моей реализации помимо шума, царапин и выцветания также есть круглые пятна.
extent = 0.8 (число с плавающей точкой) - коэфф силы фильтра
Далее по порядку:
1) Используем функцию выцветания (см. соответствующий пункт)
2) Добавляем шум, а именно:
создаем матрицу случайных значений в диапазоне (-30*extent, 30*extent)
Далее ее просто складываем с изображением (cv2.add() матричное сложение по сути) 
3) Царапины и пятна
Создается маска черного цвета
Два цикла: 
- В первом добавляются последовательные линии белого цвета
- Во втором окружности желтоватого цвета *(1,12,17)*
Далее маска размывается и накладывается сложением на исходное изображение.

### Функция неонового эффекта (выделение контуров объектов и их последующее подсвечивание).
Принимает исходное изображение и B,G,R параметры цвета неона.
1) Удаление шума - для последующего выделения контуров изображения оператором Лапласа нужно удалить шум при помощи гауссовского размытия
Размытие гаусса:
- Вырается ядро, например 3x3 (матрица) 
- Для каждого пикселя берется окрестность ядра с ним в центре и для каждого пикселя в этом ядре вычисляется значение по "колоколу Гаусса"
- Выбирается пиксель, Вокруг него берется окрестность того же размера, что и ядро
- Считается их скалярное произведение: каждый пиксель умножается на соответствующий ему вес из ядра, а затем все результаты складываются.
- Полученное число записывается в центр нового изображения.
2) Перевод в оттенки серого (см соответствующий пункт), для последующего применения цвета пользователя к маске.
3) Выделение контуров объектов оператором Лапласа: **cv2.Laplacian(neon,cv2.CV_64F,dst=None,ksize=5)**
Оператор Лапласа - <img width="227" height="39" alt="image" src="https://github.com/user-attachments/assets/e2449c83-7002-4998-aef0-57ee8b68f5ec" />
Это вторая производная (скорость изменения наклона)
Так как изображение функция дискретная, то Лаплассиан аппроксимируют следующим образом: для пикселя - <img width="261" height="35" alt="image" src="https://github.com/user-attachments/assets/d51be06f-8ad9-4b1c-be12-a52a5f9481e6" />
В точках ребер (контуров объектов) оператор равен 0, а рядом с ними положителен и отрицателен (через границу контура), поэтому на выходе получается матрица размера исходного изображения с отрицательными положительными и нулевыми (контуры) значениями
4) Для того, чтобы не потерять отрицательные значения применяем модуль **cv2.convertScaleAbs(neon)**
5) Пороговая обработка: **(cv2.threshold(neon, 70, 255, cv2.THRESH_BINARY))[1]** - оставляем только контуры(яркие участки)
Все пиксели тусклее 70 делаем 0, остальные белыми 255.
6) Далее создаем матрицу цвета и умножаем каждый пиксель на нее, придаем цвет нашим контурам
  ```    
  bgr_matrix = np.array([[B],[G],[R]])#Матрица цвета
  neon = cv2.transform(neon, bgr_matrix) #Возвращаем обратно в BGR
  ```
7) Копию маски сильно замыляем размытием гаусса **cv2.GaussianBlur(neon, (51,51), 20)**, тем самым получаем свечение
8) Складываем маски - совмещаем контуры и свечение
9) Затемняем изображение, чтобы избежать переполнения на ярких изображениях.
10) Накладываем маску (наш эффект неона) с помощью матричного сложения


# 📖 Инструкция по запуску скрипта обработки изображений

Данный скрипт (`main.py`) представляет собой консольное приложение для применения различных фильтров к изображениям. Он использует библиотеку `argparse` для приема аргументов командной строки.

## 📂 Подготовка к запуску

1. Убедитесь, что у вас установлены необходимые библиотеки. Если нет, выполните в терминале/консоли:
   ```bash
   pip install opencv-python numpy
   ```
2. Файлы `main.py` (главный скрипт) и `filters.py` (файл с функциями фильтров) должны находиться **в одной папке**.
3. Изображение, которое вы хотите обработать (например, `cat.jpg`), должно лежать в той же папке (или вам нужно будет указать полный путь к нему).

---

## ⚙️ Синтаксис и аргументы

Общая структура команды выглядит так:
`python main.py -i <путь_к_фото> -f <название_фильтра> [дополнительные_параметры]`

### Основные аргументы
| Аргумент | Длинная версия | Обязательный | Описание |
| :--- | :--- | :---: | :--- |
| `-i` | `--image` | **Да** | Путь к исходному изображению (например, `cat.jpg`). |
| `-f` | `--filter` | **Да** | Название фильтра (см. список ниже). |
| `-o` | `--output` | Нет | Имя файла для сохранения. По умолчанию: `result.jpg`. |

### Дополнительные параметры (зависят от фильтра)
| Аргумент | Длинная версия | По умолчанию | Для каких фильтров | Описание |
| :--- | :--- | :---: | :--- | :--- |
| `-e` | `--extent` | `0.8` | `oldPhoto`, `fadeColor` | Степень интенсивности эффекта (от 0.1 до 1.0). |
| `-w` | `--width` | `500` | `resize` | Новая ширина изображения в пикселях. |
| | `--height` | `500` | `resize` | Новая высота изображения в пикселях. |
| | `--B` | `1.0` | `neon` | Коэффициент синего канала для неона. |
| | `--G` | `0.1` | `neon` | Коэффициент зеленого канала для неона. |
| | `--R` | `0.4` | `neon` | Коэффициент красного канала для неона. |

---

## 🚀 Как запускать (в зависимости от среды)

### Вариант 1: В консоли Spyder (IPython)
Если вы запускаете скрипт из консоли внизу экрана Spyder, **обязательно** ставьте восклицательный знак `!` перед словом `python`, иначе консоль попытается выполнить это как код Python и выдаст `SyntaxError`.

```python
# Пример запуска неона в Spyder
!python main.py -i cat.jpg -f neon --B 0.9 --G 0.2 --R 0.6
```
*(Также можно использовать магическую команду `%run main.py -i cat.jpg ...`)*

### Вариант 2: В обычном терминале (CMD, PowerShell, Bash)
Откройте терминал, перейдите в папку с файлами (`cd путь/к/папке`) и вводите команды **без** восклицательного знака.

```bash
# Пример запуска в обычном терминале
python main.py -i cat.jpg -f neon --B 0.9 --G 0.2 --R 0.6
```

## 💾 Как сохранить результат под своим именем
По умолчанию все картинки сохраняются как `result.jpg` (и перезаписывают друг друга). Чтобы сохранить результат под конкретным именем, добавьте флаг `-o` в конец команды:
