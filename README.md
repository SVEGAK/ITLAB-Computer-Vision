# For ITLAB lab projects

## Метод `neon_effect`

Метод `neon_effect(img, B, G, R, extent, glow)` создает неоновый эффект на изображении `img`. Параметры `B`, `G` и `R` задают цвет неона в формате BGR, `extent` управляет выделением границ, а `glow` — интенсивностью свечения.

Параметр `extent` должен находиться в диапазоне от `0` до `1`, а `glow` — от `0` до `10`; при нарушении диапазонов метод вызывает `ValueError`. При `extent == 0` возвращается копия исходного изображения без обработки. Чем меньше `extent`, тем уже исходные границы, выделяемые эффектом; при значениях меньше `0.75` дополнительно используется лапласиан для отбора наиболее выраженных контуров.

Сначала изображение преобразуется к `float64` и размывается фильтром Гаусса. Размер ядра рассчитывается по `extent`, остается нечетным и не может быть меньше `3`. Затем из размытого изображения получают градации серого и вычисляют модуль градиента с помощью операторов Шарра. К градиенту применяется пороговая обработка, после чего при `extent < 0.75` он объединяется с бинарной маской, построенной на основе лапласиана, через геометрическое среднее.

Полученная маска преобразуется в заданный цвет BGR. Для создания свечения цветная маска дополнительно размывается фильтром Гаусса: параметр `glow` изменяет `sigma` от `1` до `9`, а размер ядра подбирается нечетным и пропорциональным радиусу размытия. Исходная цветная маска и ее размытая копия складываются.

Перед наложением эффекта исходное изображение затемняется с коэффициентом `0.6`, чтобы уменьшить риск переполнения яркости. Затем затемненное изображение складывается с неоновой маской с насыщением значений в диапазоне `uint8`, и результат возвращается в формате BGR.
